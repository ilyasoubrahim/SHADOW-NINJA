# SHADOW NINJA — The Last Warrior

A small responsive 2D ninja fighting game built with HTML, CSS and JavaScript Canvas. No framework, package installation or paid service is required.

## Play locally
Open `index.html` in a modern browser.

## Controls
- **A / D** or **← / →**: move
- **Space**: jump
- **J**: attack
- **K**: dodge
- On phones and tablets, use the on-screen controls.

## Features
- Five themed worlds and progressively harder stages
- Regular enemies and boss encounters
- Health bars, attack effects, coins and local progress saving
- Keyboard and touch controls
- Responsive layout; works offline after first opening

## Publish with GitHub Pages
The workflow in `.github/workflows/pages.yml` publishes this static game automatically whenever changes are pushed to `main`. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source if it is not already selected.
